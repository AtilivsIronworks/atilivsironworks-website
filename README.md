# Atilivs Ironworks website — Phase 2

Static HTML/CSS website for Cloudflare Pages. No build step required.

## Publishing
Upload the CONTENTS of this folder to the root of the `atilivsironworks-website` GitHub repository, preserving folder structure. GitHub commits trigger Cloudflare Pages deployments.

## What is included
- Homepage, Works gallery, 8 individual work pages, Research, Articles, About, Contact.
- Shared CSS at `assets/style.css`.
- Explicit placeholders for photographs and unverified bibliographies.

## Before publishing
- Verify descriptions and details against original project records.
- Replace photo placeholders with actual images.
- Confirm email and social profile URLs before adding them.
- Check all links and responsive layouts.

## Future content
Duplicate a work-page directory as a template; update its HTML and add a card to Works. No framework or database is needed at this stage.
